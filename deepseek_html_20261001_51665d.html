Слайд 3 · Теория

📘 Подпрограммы: два вида

В Python любая подпрограмма объявляется словом def. Вид определяется наличием return.

📋 Процедура

  • Выполняет действие
  • Не возвращает значение
  • Нет return
  • Пример: print()

🧮 Функция

  • Вычисляет значение
  • Возвращает через return
  • Есть return с результатом
  • Пример: int()
✅
Смотрим на тело: есть return → функция. Нет → процедура.
Слайд 4 · Синтаксис

🎁 Процедура без параметров

Наведи мышкой на строки кода — увидишь, где заголовок, где тело, а где вызов.

🔍 Схема синтаксиса заголовок тело вызов
def имя_функции(): заголовок команда 1 тело команда 2 тело имя_функции() вызов

📛 Правила именования

  • Можно буквы, цифры и _: my_func, func2
  • Нельзя начинать с цифры: 2func — ошибка
  • Нельзя пробелы: my func — ошибка
  • Имя должно быть понятным: print_receipt, а не f1
⚠️
Описание подпрограммы не выполняет её. Нужен вызов — имя со скобками.

Слайд 8 · Параметры

📦 Процедура с параметром

Процедура выше всегда печатает одно и то же. А если нужно по-разному? Добавим параметр — «окошко» для значения.

🔍 Схема синтаксиса заголовок тело вызов
def имя_функции(параметр): заголовок с параметром команда 1 (использует параметр) тело команда 2 тело имя_функции(значение) вызов с аргументом
💡
Параметр — переменная в заголовке. Аргумент — значение при вызове. Они связываются: параметр = значение.

Слайд 11 · Различаем

🔍 Процедура или функция?

Определи вид по коду. Есть return → функция, нет → процедура.

Что это?
def show(a, b): print(a + b)
А это?
def get(a, b): return a + b
И это?
def double(x): return x * 2
А это?
def line(): print("-----")
Слайд 12 · Функция

↩️ Функция возвращает результат

Функция — та же подпрограмма, но она возвращает значение через return.

def add(a, b): return a + b   r = add(2, 3) # r = 5 print(add(10, 20) * 2) # 60
✅
Процедура напечатала и забыла. Функция вернула результат — используй в формулах, сравнивай, складывай.
⚠️
После return функция завершается. Всё, что ниже — не выполнится.
