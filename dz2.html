Задача 3

Функция с return

Напиши функцию discount(price, percent), которая возвращает цену со скидкой.
Формула: price * (1 - percent / 100)
Проверь её на двух своих примерах — придумай цену и процент сам. Выведи результат через print().
Например:
print(discount(1000, 10)) → 900.0
print(discount(500, 20)) → 400.0
💡 Подсказка:
Здесь нужен return — это функция, а не процедура.
def discount(price, percent):
    return price * (1 - percent / 100)
Потом — два print(discount(...)) с любыми числами.
