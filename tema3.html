Слайд 10 · Перебор элементов массива

🚶 Перебор элементов массива

Цикл for позволяет применить одну и ту же команду ко всем элементам массива. Не нужно повторять код — пишем один раз, работает для каждого.

nums = [3, 7, 2]   for x in nums: print(x * 10) # 30, 70, 20
💡
Если нужен новый массив — создай пустой и добавь результаты через .append().
nums = [3, 7, 2] result = [] for x in nums: result.append(x * 10) print(result) # [30, 70, 20]
