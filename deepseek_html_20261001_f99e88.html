🖨️ Вывод на экран

Функция print() печатает значения на экран. Можно передать несколько значений — они разделятся пробелом.

print("Привет!") print("Возраст:", 16) print("Сумма:", 2 + 3)
💡
Между значениями в print() автоматически ставится пробел. Если он не нужен — используй sep="".

⌨️ Ввод с клавиатуры

Функция input() ждёт, пока пользователь введёт строку, и возвращает её.

# Возвращает строку name = input("Как тебя зовут? ") # Для чисел — преобразуем age = int(input("Возраст: ")) price = float(input("Цена: "))
⚠️
Важно: input() всегда возвращает строку. Для математики нужно преобразовать: int() — целое, float() — дробное.

📝 Строки

Строка — это текст в кавычках. Бывают двойные "..." и одинарные '...' — оба варианта работают.

name = "Аня" greeting = "Привет, " + name # склеивание print(greeting) # Привет, Аня # Умножение строки print("=" * 10) # ==========

🔀 Условия (if / elif / else)

Позволяют выполнять разный код в зависимости от условия.

if age >= 18: print("Совершеннолетний") elif age >= 14: print("Подросток") else: print("Ребёнок")

Операции сравнения

==равно
!=не равно
>, <больше, меньше
>=, <=больше или равно, меньше или равно
💡
После if, elif, else — двоеточие, а тело — с отступом (4 пробела).

🔁 Циклы (for / while)

Цикл for — когда знаем количество

for i in range(5): print(i) # 0 1 2 3 4 for i in range(1, 6): print(i) # 1 2 3 4 5

Цикл while — пока условие истинно

count = 0 while count < 3: print("Шаг", count) count = count + 1
⚠️
В цикле while нужно менять условие внутри, иначе он будет бесконечным.

🧩 Подпрограммы

Подпрограмма — именованный блок кода. В Python объявляется словом def. Бывает двух видов:

📋 Процедура — не возвращает значение

def greet(name): print("Привет,", name) greet("Аня") # Привет, Аня

🧮 Функция — возвращает значение через return

def add(a, b): return a + b result = add(2, 3) # result = 5 print(add(10, 20) * 2) # 60

Как определить вид

ПризнакВид
Есть return с результатомФункция
Нет returnПроцедура
💡
Описание подпрограммы не выполняет её. Нужен вызов — имя со скобками.

🐛 Частые ошибки

SyntaxError — ошибка синтаксиса

def greet(name) # забыли : print("Привет")

→ Python ждёт двоеточие после заголовка.

IndentationError — ошибка отступа

def greet(): print("Привет") # нет отступа

→ Тело подпрограммы должно быть с отступом (4 пробела).

NameError — неизвестное имя

greet() # вызвали до описания def greet(): print("Привет")

→ Подпрограмма должна быть описана раньше, чем вызвана.

ValueError — неправильное значение

x = int("привет") # нельзя превратить в число

→ int() работает только со строками из цифр.
